🧬 Anatomia do funil · 4 camadas

Cada camada tem uma função específica no stack do afiliado. Clicar a URL do Meta ad → passa por 4 redirects → chega no checkout Shopify.

1🌐 ClickFunnels Wrapper (Cloaker)
https://www.burnhackmethod.com/linfa-adv1?rtkcid=6a8b6695e997211587bd83be&rtkcmpid=6a808f3f9dbfc82afd6f4979
Função: esconde a URL real do LP do Facebook ad review. Mostra "burnhackmethod.com" (parece genérico, white hat) pro Meta bot.
Tecnologia: ClickFunnels pages (badge "Powered by ClickFunnels" no footer). Cloudflare CDN na frente (esconde IP de origem).
Por que existe: a LP real (SlimSoda) tem depoimentos pesados, FDA disclaimer, before/after que quebra o Meta ad review. Cloaker = URL "limpa" pro Meta aprovar.
Custom path: /linfa-adv1 = afiliado chamou de "linfedema ad variant 1" — indica cluster alvo.
↓
2📊 RedTrack Tracker (atribuição)
?rtkcid=6a8b6695e997211587bd83be&rtkcmpid=6a808f3f9dbfc82afd6f4979
Função: passa parâmetros de atribuição sem alterar URL visível. rtkcid = RedTrack click ID, rtkcmpid = RedTrack campaign ID.
Tecnologia: RedTrack (redtrack.io) é um tracker de afiliados que mede click → conversão. Similar a Voluum / BeMob.
Por que existe: afiliado precisa saber qual campanha/clique converteu pra otimizar bids. Sem tracker = sem dados = sem scale.
Custo: $99-299/mês RedTrack self-host.

https://shopzenvylite.com/pages/slimsoda-buy-1-tub-get-1-free
Função: converte visitante em buyer. Long-form advertorial com testemunhas + pricing + comments + compliance.
Tecnologia: Shopify page (theme "PHX 3.0 Checkout Builder 4/24/26"). MyShopify domain: 8hu1da-yg.myshopify.com. Shop ID 102693011801.
Quem controla: vendor SlimSoda/Zenvy (não o afiliado). Copy idêntica à nossa Maria 47 v4.7.1.
Pixel: Facebook Pixel 1722542328996849 (LP) + 1886256968996709 (cloaker) = double pixel pattern.
↓
4💳 Funnelish Checkout (Shopify)
https://secureorder.shopzenvylite.com/funnelish?store=8hu1da-yg&funnelishId=544
Função: processa pagamento. Apple Pay, Google Pay, PayPal, credit card.
Tecnologia: Funnelish (funnelish.com) é um funnel builder que cria checkout pages em Shopify. funnelishId=544 = ID do funil.
Quem controla: vendor SlimSoda/Zenvy (afiliado não toca checkout — só recebe commission).
Receita split: afiliado recebe commission por venda (provavelmente 30-50% de $29.99 = $9-15/venda).

🎯 Cluster strategy: "linfa-adv1" + LP cross-sell

O nome do path no cloaker (linfa-adv1) revela o cluster que o afiliado está atacando. Mas a LP é SlimSoda, não Linfaflow. Isso é cluster cross-sell — uma técnica afiliado onde você segmenta avatar de produto A mas vende produto B (com funil similar).

🔍 Cluster source (segmentado no Meta)

"Linfedema / legs swollen 50-70 women"

Avatar: mulher 50-70, queixa de pernas inchadas no fim do dia, retenção de líquido, peso acumulado após menopausa.

Por que esse cluster: dor física visível, emocional (não consegue usar sapatos, evita praia), e já tá em "research mode" (procurou sintomas antes).

Tamanho estimado: 2-5M mulheres USA (50-70 com queixa lymphedema-like).

🛒 Produto destino (LP no click)

SlimSoda (Adv2 anti-scam)

Mecanismo: baking soda + ginger + berberine (3 ingredientes em ordem).

Por que SlimSoda serve pro cluster: a LP fala de "store vs burn", "socks leave deeper marks by 5pm", "weight around the middle" — dor cross-cluster (linfedema + weight gain menopausal).

Lógica do afiliado: LP não menciona linfedema diretamente. Foca em "socks marks" + "weight around middle" que servem ambos clusters.

🧠 Por que cross-cluster funciona aqui: o avatar 50-70 feminino tem múltiplas queixas sobrepostas (weight + lymph + hormones + energy). A LP oficial SlimSoda é escrita em linguagem que ressoa em todas essas queixas sem focar em nenhuma especificamente. O afiliado descobre que cluster convert melhor via spy/redtrack e ajusta o cloaker path pra cada teste.

⚖️ Compliance analysis · gray hat ou red line?

O uso de cloaker em si é gray hat — não é explicitamente ilegal, mas está numa zona cinza que Meta e FTC podem questionar.

✅ Gray hat (aceitável)

  • Usar cloaker pra passar Meta ad review (esconde LP pesada do bot)
  • Embedar Facebook Pixel no cloaker (tracking legítimo)
  • RedTrack tracker (atribuição é prática padrão)
  • Vendor oficial controla LP (copy compliance OK, FDA disclaimer presente)
  • Compliance footer completo (FDA, "not a cure", "individual results vary")
  • 1,342 comments (vendor mantém, não cria fake)

❌ Red line (cruzado)

  • Nada óbvio. LP é compliance-safe.
  • Mas: cluster "linfedema" via cloaker name pode ser considerado targeting de health condition (Meta 2026 baniu health targeting em vários casos)
  • Microsoft Clarity rodando em LP = vendor vê session replay de todos users (privacy gray area, GDPR/CCPA)
  • Double pixel pattern (cloaker + LP) = double counting risk (Meta vê 2 PageViews por user, attribution confusa)
  • Shopify MCP endpoint exposto = AI agent pode comprar automaticamente (futuro risk)
🛑 Risco real do afiliado: Meta pode detectar cloaker pattern (URL limpa + redirect + heavy LP) via manual review e banir a conta do afiliado. Em 2026, Meta aperta cloaker detection. Affiliate networks como ClickFunnels + RedTrack não protegem afiliado se Meta flag a conta.

Risco do vendor (Zenvy/SlimSoda): se 50+ afiliados diferentes apontam cloaker pro mesmo LP, o vendor é que responde pelo compliance do LP (que está OK). Vendor é blindado.

Step-by-step

  1. Apply to vendor affiliate program — SlimSoda/Zenvy aceita afiliados via FlexOffers, ShareASale, ou direto. Commission típica: 30-50% de $29.99 = $9-15/venda.
  2. Get unique tracking link — vendor dá link tipo shopzenvylite.com/?aff=YOURID. Você envelopa com seu tracker.
  3. Set up RedTrack campaign — criar campaign, gerar rtkcid + rtkcmpid, apontar pra vendor link.
  4. Build ClickFunnels cloaker page — página "white hat" genérica (ex: "Burn Fat Naturally" + image + CTA "Learn More").
    CTA aponta pra seu RedTrack link (que redireciona pro vendor LP).
  5. Install Facebook Pixel on cloaker — dispara PageView, ViewContent, AddToCart (via vendor events passback).
  6. Cloudflare proxy — point DNS do seu cloaker domain pra Cloudflare, hide IP origem ClickFunnels.
  7. Submit ad to Meta — ad vai ser reviewed, cloaker URL passa (parece white hat), Meta aprova.
  8. User clicks ad → cloaker fires pixel → RedTrack tracks → redirect to vendor LP → vendor LP fires second pixel → user buys → vendor attributes to your aff=YOURID → commission.

🧠 Aprendizado chave · 3 takeaways

1. Copy é commodity, infra é vantagem.
O afiliado não escreve copy própria. A LP é idêntica à nossa Maria 47 v4.7.1 (mesmas testemunhas, pricing, compliance). Logo, copy não é diferencial competitivo — qualquer um pode copiar.

O que é diferencial: (1) cloaker que passa Meta review, (2) tracker que atribui conversion, (3) cluster targeting inteligente (linfedema → SlimSoda cross-sell), (4) speed de iteração (criar novo cloaker path em minutos, testar novo cluster).
2. Cluster cross-sell é mais forte que copy personalization.
Em vez de escrever LP específica pra cluster "linfedema" (alto custo, alto risco), o afiliado segmenta cluster no Meta e envia tráfego pra LP genérica que ressoa em múltiplas queixas (weight + lymph + hormones + energy).

Lição pra gente: não precisa de LP nova por cluster. Maria 47 v4.7.1 já fala em linguagem que serve weight + lymph + menopause. O que falta é cluster-targeted ad creative (Brief #1 anti-scam, Brief #2 Stanford, brief Sardinian centenarian) que aponta pra mesma LP.
3. Vendor Zenvy/SlimSoda é o "shopify of direct response" pra esse cluster.
O vendor fornece: (1) LP compliance-safe, (2) checkout Funnelish+Shopify, (3) compliance footer, (4) comments section, (5) trust seals, (6) pixel integration. Afiliado só fornece tráfego + cluster targeting.

Isso é o modelo "offer + funnel as a service". Affiliado é tráfego broker, vendor é funil broker. Ambos ganham.

Lição pra gente: se quisermos ser vendor (white label), precisamos oferecer: LP compliance-safe + checkout próprio + comments section + trust seals + pixel wired + commission structure. SlimSoda/Zenvy já é esse template. MemoPryl/Linfaflow/Cardio Clear ainda não.

🎯 Recomendações operacionais

1. Não tentar competir em copy

Copy SlimSoda é commodity. Vendor Zenvy já é winner. Não reescrever.

Ação: usar Maria 47 v4.7.1 como LP principal. Briefs #1 e #2 são ad creative, não LP.

2. Focar em cluster-targeted creative

Brief #1 anti-scam + Brief #2 Stanford + Sardinian centenarian = 3 clusters diferentes apontando pra mesma LP.

Ação: produzir 3 criativos UGC, A/B test em 3 ad sets, mesma LP.

3. Investigar cluster "linfedema/legs swollen"

O afiliado burnhackmethod descobriu que cluster linfedema/legs swollen 50-70 converte SlimSoda. Por que? Linguagem de "socks leave marks" + "weight around middle" ressoa.

Ação: brief #6 Linfaflow (já no pipeline) + brief "legs swollen" SlimSoda cross-sell.

4. Spy ativo 24h

Esse cloaker é só 1 exemplo. Existem dezenas de afiliados SlimSoda com cloakers similares.

Ação: spy tool (AdPlexity $99/mês) pra monitorar cloakers ativos.

5. Replicar infra se virar vendor

Se a gente quiser vender MemoPryl/Linfaflow via afiliados, precisa do stack: LP compliance + checkout + pixel + commission.

Ação: replicar infra Zenvy (LP + Funnelish + Shopify) pra MemoPryl.

6. Documentar cloaker patterns

Cada cloaker novo que aparece revela novo cluster targeting. linfa-adv1 = linfedema cluster. Próximo: sardi-adv1? hrt-adv1?

Ação: spy semanal de cloaker paths → mapear clusters ativos.
