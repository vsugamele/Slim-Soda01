## Por que GIF e não vídeo?

Os GIFs são **arte editorial** com texto sobreposto animado — visualmente funcionam como VSL de "scroll lento" (cada GIF = um bloco de copy). Servem pra:

1. Quem não tem banda pra vídeo (mobile low-end)
2. Page speed (GIFs <6MB vs 2GB de vídeo)
3. Reutilização: cada GIF pode virar um criativo Meta isolado
