📐 Árvore de decisão — "qual skill aciono?"

Pra cada objetivo, qual é a skill primária?

  1. Escrever copy do zero (ad, LP, VSL, email) → rebel-copy + avatar-architect + mecanismo-unico-v2
  2. Provar um claim grande → weaponized-credibility + proof-elements
  3. Melhorar ad/LP/VSL já validado → dtc-control (8 alavancas, 1 por vez)
  4. Analisar performance e achar padrões → niche-research (4 blocos)
  5. Escrever VSL standalone → vsl-filemon (Método E3)
  6. Montar página de venda → lp-persuasiva-v2 (16 blocos)
  7. Auditar copy pronta (camada qualidade) → sala-de-guerra-copy
  8. Carga emocional extrema (manifesto) → devastador-v4
  9. Oferta de entrada baixo ticket → tripwire-matador-v2
  10. Spy de competidores → competitive-ads-extractor + angulos-criativos
  11. Mecanismo único branded → mecanismo-unico-v2
🚫 Regra de ouro (NUNCA viole): 1 skill primária por vez. Você pode compor 2-3 skills (ex: rebel-copy + proof-elements), mas nunca 5 ao mesmo tempo — vira Frankenstein. Sequência canônica: avatar-architect → mecanismo-unico → rebel-copy → weaponized-credibility/proof-elements → dtc-control (iterar) → niche-research (analisar).
