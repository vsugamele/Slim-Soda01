🛠️ Como configurar

3 env vars que destravam 80% do sistema

  1. Acesse Vercel → vercel.com/vsugamele/slim-soda01/settings/environment-variables
  2. Adicione cada env var abaixo (clique no nome pra ver o que é):
🔥
META_ACCESS_TOKEN
Token do pixel pra CAPI + Meta dashboard live. Crítico.
MISSING
Como gerar:
  1. Vá em business.facebook.com/events_manager
  2. Selecione o pixel 1619587959397761
  3. Configurações → Gerar token de acesso
  4. Copie e cole aqui no Vercel
🔥
META_AD_ACCOUNT_ID
ID da conta de anúncios (act_XXXXX). Liga o Meta real-time dashboard.
MISSING
Como achar: business.facebook.com/settings/ad-accounts → o número depois de act=
⚙️
META_TEST_CODE
Código de teste pra disparar evento real pelo ?test=1. Opcional.
OPTIONAL
Como gerar: Events Manager → Test Events → Copy code
⚙️
SUPABASE_SERVICE_ROLE_KEY
Permite migration automática + admin tasks. Opcional (manual SQL funciona).
OPTIONAL
Como achar: Supabase Dashboard → Project Settings → API → service_role key
⚙️
CRON_SECRET
Protege os cron jobs de serem chamados por qualquer um. Recomendado.
OPTIONAL
Como gerar: openssl rand -hex 32 (qualquer string aleatória de 32 chars)

🧪 Testar depois de configurar

  1. Depois de setar as env vars, faça Redeploy (Vercel → Deployments → 3 pontos → Redeploy)
  2. Teste os endpoints: 
    curl https://slim-soda01.vercel.app/api/track-capi
curl https://slim-soda01.vercel.app/api/meta-campaigns?range=7d
  3. Volte aqui pra ver o status atualizar: GET /api/env-checklist
  4. Se tudo OK, o dashboard Meta sai de DEMO pra LIVE
